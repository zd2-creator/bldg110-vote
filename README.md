# bldg110-vote — בחירת חברת בדק (בניין 110)

טופס הצבעה בין לעד הנדסה לכהן הנדסה + מסך אדמין. עובד על GitHub Pages מול Google Apps Script.

## מה תוקן בגרסה הזו (יולי 2026)
- **הסיסמה לא נמצאת יותר בקוד** — נבדקת בצד השרת בלבד (Script Properties).
- **ה-API לא חושף נתונים אישיים**: הדף הציבורי מקבל רק מיפוי דירה→בחירה (`action=stats`). שמות, טלפונים וחתימות מוחזרים רק עם סיסמת אדמין (`action=getAll` ב-POST).
- בדיקת "דירה כבר הצביעה" עברה לשרת (כולל נעילה נגד מרוץ), עם ולידציה של כל השדות.

## Backend
קוד ה-Apps Script המשותף נמצא בריפו `bldg110` בקובץ `apps-script/Code.gs` — פריסה אחת משרתת את שני האתרים. הוראות הפעלה מלאות ב-README של `bldg110`.

אחרי הפריסה, החלף את `PASTE_APPS_SCRIPT_DEPLOYMENT_URL_HERE` ב:
- `vote.html`
- `vote-admin.html`
